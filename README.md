# Agent skills

A small collection of personal skills for Codex and Antigravity. Each skill follows the `SKILL.md` format and can be installed on its own.

## Skills

- `project-feature-work`: implement scoped changes in an established codebase.
- `ux-review-and-fix`: diagnose usability problems and make requested fixes.
- `feature-planning`: compare approaches before implementation.
- `verify-changes`: run requested checks and report their limits.
- `evidence-based-project-writing`: write project material from code, references, and history.
- `speak`: apply the writing and teaching preferences used across the other skills.

## Install

Copy any skill folder into the agent's global or project-level `skills/` directory. Codex and Antigravity both discover skills containing a `SKILL.md` file.
